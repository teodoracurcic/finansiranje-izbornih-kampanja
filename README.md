# Finansiranje izbornih kampanja u Srbiji

Prihodi i rashodi izbornih lista na parlamentarnim izborima 2016, 2020, 2022. i 2023. godine, prema konačnim izveštajima sa portala Agencije za sprečavanje korupcije.

Stranica: https://teodoracurcic.github.io/finansiranje-izbornih-kampanja/

**Podaci nisu provereni.** Zbirovi su preuzeti iz izveštaja koje su liste same predale.

## Fajlovi

- `index.html` je stranica
- `finansiranje kampanje zbirno.xlsx` su podaci, sa listovima `prihodi` i `rashodi`

Stranica čita Excel iz istog foldera. Za nove izbore dovoljno je dopuniti Excel.
